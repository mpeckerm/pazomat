# תחנות רחיצה פזומט – אפליקציה אישית

אפליקציה אישית שמציגה את תחנות הרחיצה של פזומט על מפה, עם חיפוש, "לידי", "פתוח עכשיו" וניווט ב-Waze או ב-Google Maps.

התוצר הסופי הוא קובץ אחד: `index.html`. הוא כולל את כל הקוד, את ספריית המפה ואת נתוני התחנות, ונפתח מקישור קבוע.

## הארכיטקטורה בקצרה

- **האפליקציה:** קובץ `index.html` אחד. אין שרת, אין מסד נתונים ואין הרשמה.
- **אחסון:** GitHub Pages. הקישור קבוע ולא משתנה בעדכונים.
- **עדכון הנתונים:** GitHub Actions מריץ את `scripts/update.py` בכל פעם שמעלים קובץ חדש. הסקריפט קורא את ה-Excel, מאתר מיקומים, משווה לגרסה הקודמת ובונה מחדש את `index.html`.
- **עריכות ידניות:** שעות פעילות ומיקומים מתוקנים נשמרים בקובץ `data/overrides.jsonl`, ולא נמחקים בעדכונים.

## שירותים חיצוניים ועלויות

| שירות | למה | עלות |
|---|---|---|
| GitHub (מאגר ציבורי) | שמירת הקבצים | חינם |
| GitHub Pages | אירוח האפליקציה | חינם במאגר ציבורי |
| GitHub Actions | עדכון נתונים ותזכורת חודשית | חינם ללא הגבלה במאגר ציבורי |
| OpenStreetMap (אריחי מפה) | תצוגת המפה | חינם, לשימוש מתון עם קרדיט |
| Leaflet | ספריית המפה, מוטמעת בקובץ | חינם (קוד פתוח) |
| Nominatim | איתור מיקום לפי כתובת, רק בזמן עדכון | חינם, עד בקשה אחת לשנייה |
| OSRM (שרת ציבורי) | מרחק וזמן נסיעה ל-10 התחנות הקרובות | חינם, ללא התחייבות לזמינות |
| קישורי Waze ו-Google Maps | ניווט | חינם, קישור רגיל ללא API |

אף שירות לא דורש כרטיס אשראי או מפתח API. העלות החודשית: 0.

אם שרת OSRM לא זמין, האפליקציה מציגה מרחק אווירי ומודיעה על כך.

## הוראות שלב אחר שלב

### 1. העלאה לאינטרנט (פעם אחת)

1. היכנס ל-github.com (או צור חשבון חינמי).
2. לחץ **New repository**. שם: `pazomat`. בחר **Public**. לחץ **Create repository**.
3. במסך המאגר החדש לחץ **uploading an existing file**.
4. פתח את קובץ ה-ZIP במחשב, וגרור את **כל התוכן שבתוך התיקייה** (כולל התיקייה `.github`) לחלון הדפדפן. לחץ **Commit changes**.
5. היכנס ל-**Settings ← Pages**. תחת **Source** בחר **GitHub Actions**.
6. ההעלאה מפעילה הרצה ראשונה אוטומטית. היא לוקחת כ-5 עד 10 דקות, כי היא מאתרת מיקום לכל 140 התחנות. אם שלב הפרסום בה נכשל (סימן אדום), זה בגלל שסעיף 5 בוצע אחריה.
7. היכנס ל-**Actions**, בחר **עדכון נתונים ופרסום** ולחץ **Run workflow**. ההרצה הזו מהירה.
8. בסיום, הקישור יופיע ב-**Settings ← Pages**, בערך כך: `https://<שם-המשתמש>.github.io/pazomat/`

אם התיקייה `.github` לא עלתה (במק היא מוסתרת): לחץ **Add file ← Create new file**, כתוב בשם `.github/workflows/build.yml`, הדבק את תוכן הקובץ, ושמור. חזור על זה גם עבור `reminder.yml`.

### 2. פתיחה ובדיקה במחשב ובטלפון

1. פתח את הקישור במחשב. ודא שהמפה והתחנות מוצגות.
2. שלח לעצמך את הקישור, ופתח אותו בטלפון.
3. לחץ **לידי** ואשר הרשאת מיקום. התחנות הקרובות יוצגו לפי מרחק.
4. לחץ על תחנה ובדוק את כפתורי Waze ו-Google Maps.

### 3. התקנה במסך הבית

- **אייפון (Safari):** כפתור השיתוף ← **הוסף למסך הבית**.
- **אנדרואיד (Chrome):** תפריט שלוש הנקודות ← **הוספה למסך הבית** או **התקנת אפליקציה**.

### 4. הוספת שעות פעילות לתחנה

1. באפליקציה, פתח את התחנה ← **עריכת שעות ומיקום**.
2. קבע שעות לימים א'–ה', שישי ושבת, ולחץ **שמור שעות**. השעות נשמרות מיד בטלפון הזה.
3. לשמירה קבועה: לחץ **העתק שורה**.
4. באתר GitHub, פתח את `data/overrides.jsonl`, לחץ על העיפרון, הדבק את השורה בשורה חדשה בסוף הקובץ, ולחץ **Commit changes**.
5. אחרי כמה דקות, השעות יופיעו בקישור בכל מכשיר.

הכפתור **פתוח עכשיו** מופיע רק כשיש לפחות 5 תחנות עם שעות.

### 5. תיקון מיקום של תחנה שלא אותרה

1. **מידע ועריכות** (בתחתית המסך) ← **תחנות ללא מיקום** או **תחנות עם מיקום משוער**.
2. בחר תחנה ← **עריכת שעות ומיקום** ← **קבע מיקום במפה**.
3. לחץ על המפה במיקום המדויק.
4. לשמירה קבועה: העתק את השורה והדבק ב-`data/overrides.jsonl`, כמו בסעיף 4.

אפשר להעתיק את כל העריכות בבת אחת דרך **מידע ועריכות ← העתק את כל העריכות**.

### 6. העדכון החודשי

1. ב-1 לכל חודש ייפתח Issue בשם **זמן לעדכן את רשימת התחנות**, ותקבל על כך מייל מ-GitHub.
2. הורד את דוח תחנות פזומט (Excel) מאתר פז.
3. באתר GitHub, היכנס לתיקייה `upload` ← **Add file ← Upload files**. גרור את הקובץ ולחץ **Commit changes**.
4. בתוך כמה דקות:
   - הנתונים בקישור מתעדכנים.
   - ייפתח Issue בשם **דוח שינויים בתחנות**, עם תחנות חדשות, תחנות שהוסרו ושינויים בכתובת או בטלפון.
   - תחנות חדשות או שכתובתן השתנתה מאותרות אוטומטית.
5. סגור את ה-Issue של התזכורת.

העריכות הידניות שלך (שעות ומיקומים) נשמרות בכל עדכון.

## פרטיות

- אין הרשמה, אין Analytics ואין פרסומות.
- המיקום שלך משמש רק בתוך הדפדפן.
- לחישוב מרחק נסיעה נשלחות לשרת OSRM קואורדינטות בלבד, ללא מידע מזהה.

## הערות

- הנתונים ציבוריים ומגיעים מהדוח של פז. אין Scraping לאתר פז.
- שעות פעילות לא מופיעות בדוח, ולכן מוזנות ידנית. חגים לא נתמכים.
- לקישור קבוע למקור הנתונים: ערוך את `sourceUrl` בקובץ `data/config.json`.
